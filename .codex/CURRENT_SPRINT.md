# Current Sprint

## Sprint

Sprint 0 — Foundation.

## Objective

Establish an enterprise-grade repository foundation for MonPiole Platform without implementing business logic.

## In scope

- Monorepo structure and ownership documentation.
- Root governance and repository documentation.
- Engineering documentation for architecture, DDD, security, standards, ADRs, and operations.
- Codex task, sprint, playbook, template, and checklist locations.
- Validation of documentation links, Markdown, and Git diff before the foundation is committed.

## Out of scope

- Business features or domain workflows.
- Application runtime, framework, cloud provider, or package-manager selection.
- Deployable services, CI workflows, Docker assets, or production infrastructure.
- Credentials, tenant data, and environment-specific configuration.

## Active tasks

- TASK-001 — Bootstrap Repository Foundation.
- TASK-002 — Agent governance.

## Completion criteria

Sprint 0 is complete when the repository foundation is documented, root guidance is internally consistent, links are validated, no business code has been added, and the Git diff is ready for focused review and commit.
